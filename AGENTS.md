## About

- `rgk` is a Node.js CLI that wraps `rg` and adds LLM-powered `--keep` filtering through Codex.

## Changelog

- Any functional or contract change must include a `CHANGELOG.md` entry under **[Unreleased]** in the same change.

## Verification

- Before saying done, run `pnpm run verify` for code changes.
- Run `pnpm run pack:check` before release/package changes.
